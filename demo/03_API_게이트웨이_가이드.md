# 트래블제로 API 게이트웨이 사용 가이드

문서 버전 v3.2 · 최종 개정 2026-07-30 · 관리 부서 플랫폼팀

## 0. 한눈에 보기
- API 속도 제한은 서비스당 초당 100요청이다.
- 액세스 토큰 유효기간은 1시간이다.
- 오류 응답 형식은 RFC 9457 problem+json 이다.
- 폐기 예정 API 는 최소 90일 전에 공지한다.
- 게이트웨이 기본 응답 타임아웃은 10초다.

## 1. 인증
- 모든 내부 API 호출은 게이트웨이 `https://api.travelzero.internal` 을 경유한다.
- 인증은 서비스 계정의 OAuth2 client_credentials 토큰을 사용한다.
- 액세스 토큰 유효기간은 1시간이다. 만료 5분 전에 갱신하는 것을 권장한다.
- 사용자 토큰을 서버 간 호출에 재사용하는 것은 금지한다.

## 2. 속도 제한
- 기본 한도는 서비스당 초당 100요청(100 RPS)이다.
- 한도를 초과하면 HTTP 429와 `Retry-After` 헤더가 반환된다.
- 배치성 호출은 야간 시간대 01:00~06:00 에 수행한다.
- 배치 호출은 최소 3영업일 전에 플랫폼팀에 공지한다.
- 한도 상향은 예외 신청서로 접수하며 처리에 5영업일이 걸린다.

## 3. 오류 형식
- 오류 응답은 RFC 9457 problem+json 형식이다.
- 응답 본문은 type, title, status, detail, instance 다섯 필드를 포함한다.
- 재시도는 지수 백오프를 사용한다. 초기 대기 200ms, 최대 5회다.
- 재시도는 5xx 와 429 에만 적용한다. 4xx 는 재시도하지 않는다.

## 4. 버전 관리
- URL 경로에 메이저 버전을 둔다. 예: `/v1/orders`, `/v2/orders`.
- 하위 호환이 깨지는 변경만 메이저 버전을 올린다.
- 폐기 예정 API 는 최소 90일 전에 `Deprecation` 헤더와 공지로 알린다.
- 폐기된 API 는 410 Gone 을 반환한다.

## 5. 타임아웃
- 게이트웨이의 기본 응답 타임아웃은 10초다.
- 결제 승인 API 만 예외적으로 30초를 허용한다.
- 클라이언트 연결 타임아웃은 3초를 권장한다.
