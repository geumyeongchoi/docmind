## 업로드 방법

사이트 왼쪽 **문서** 패널에서 `파일 선택` → 01~16 을 전부 선택 → `업로드`.
여러 파일을 한 번에 올릴 수 있고, 상태가 QUEUED → PROCESSING → DONE 으로 바뀐다.
전부 DONE 이 되면 헤더의 `chunks` 숫자가 올라간다.

## 올리기 전에 확인할 것

- 현재 서버 모델은 **gemma3:1b** 다(헤더에 표시된다). README 의 수치는 gemma3:4b 로 잰 것이라
  1b 에서는 정답률이 눈에 띄게 낮게 나온다. 데모에 쓸 거라면 서버 메모리가 허락하는 선에서
  `OLLAMA_CHAT_MODEL=gemma3:4b` 로 올리는 편이 훨씬 낫다.
- 같은 파일을 다시 올리면 sha256 이 같아 DUPLICATE 로 건너뛴다. 내용을 고쳤다면 다시 올라간다.
