# 트래블제로 공통 오류 코드표

문서 버전 v2.0 · 최종 개정 2026-08-14 · 관리 부서 플랫폼팀

## 0. 한눈에 보기
- 여신 한도를 넘으면 오류 코드 E4012 가 발생한다.
- 재고가 부족하면 오류 코드 E4020 이 발생한다.
- 멱등키가 중복되면 오류 코드 E4090 이 발생한다.
- 속도 제한을 넘으면 오류 코드 E5001 이 발생한다.

응답 본문은 RFC 9457 problem+json 형식이며 `type` URI 의 마지막 경로 조각이 아래 코드다.

| 코드 | HTTP | 의미 | 클라이언트 조치 |
|---|---|---|---|
| E1001 | 400 | 요청 본문 검증 실패 | 필드를 확인하고 다시 요청한다 |
| E1002 | 400 | 지원하지 않는 파일 형식 | PDF, DOCX, MD, TXT 만 허용된다 |
| E1010 | 400 | 출발일이 과거 날짜 | 날짜를 오늘 이후로 수정한다 |
| E2001 | 401 | 토큰이 없거나 만료됨 | 토큰을 재발급한다 |
| E2002 | 403 | 권한 부족 | 권한을 신청한다 |
| E3001 | 404 | 리소스를 찾을 수 없음 | 식별자를 확인한다 |
| E4012 | 409 | 여신 한도 초과 | 한도를 확인한 뒤 재시도한다 |
| E4020 | 409 | 재고 부족 | 수량을 조정한다 |
| E4090 | 409 | 멱등키 중복 | 이전 응답을 재사용한다 |
| E5001 | 429 | 속도 제한 초과 | `Retry-After` 만큼 대기한다 |
| E9001 | 500 | 내부 오류 | 지수 백오프로 재시도한다 |
| E9002 | 503 | 의존 서비스 일시 장애 | 지수 백오프로 재시도한다 |

## 판독 요령
- E4012 는 고객의 외상 한도가 부족할 때 발생한다. 재고와는 무관하다.
- E4020 은 상품 재고가 부족할 때 발생한다. 여신과는 무관하다.
- E4090 은 같은 멱등키로 두 번 요청했을 때 발생한다. 오류가 아니라 중복 방지 동작이다.
- E9002 가 5분 이상 지속되면 장애 대응 런북의 P2 절차를 시작한다.
