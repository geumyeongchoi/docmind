# 사내 API 게이트웨이 사용 가이드

## 인증
- 모든 내부 API 호출은 게이트웨이(https://api.internal)를 경유하며, 서비스 계정의 OAuth2 client_credentials 토큰이 필요하다.
- 액세스 토큰 유효기간은 **1시간**이며 만료 5분 전 갱신을 권장한다.

## 속도 제한
- 기본 한도는 서비스당 초당 100요청(100 RPS)이다. 초과 시 HTTP 429와 `Retry-After` 헤더가 반환된다.
- 배치성 호출은 야간 시간대(01:00~06:00)에 수행하고, 사전에 플랫폼팀에 공지한다.

## 오류 형식
- 오류 응답은 RFC 9457 problem+json 형식이다: type, title, status, detail, instance 필드를 포함한다.
- 재시도는 지수 백오프(초기 200ms, 최대 5회)를 권장하며 5xx와 429에만 적용한다.

## 버전 관리
- URL 경로에 메이저 버전을 둔다(/v1, /v2). 하위 호환이 깨지는 변경만 메이저를 올린다.
- 폐기 예정 API는 최소 90일 전에 `Deprecation` 헤더와 공지로 알린다.
