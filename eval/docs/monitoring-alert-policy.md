# 모니터링·알림 정책

## 대시보드
- 모든 서비스는 RED(Rate, Errors, Duration) 대시보드를 기본으로 갖춘다.
- 대시보드 링크는 서비스 README 첫 화면에 둔다.

## 알림 기준
- 5xx 비율이 5분 평균 1%를 넘으면 경고, 5%를 넘으면 호출(page)한다.
- p99 지연이 SLO의 2배를 5분간 유지하면 경고한다.
- Kafka 컨슈머 랙 알림 임계값은 5,000이다.
- 디스크 사용률 85% 경고, 92% 호출.

## 알림 위생
- 조치할 수 없는 알림은 만들지 않는다. 2주간 아무 조치도 유발하지 않은 알림은 삭제 검토 대상이다.
- 알림에는 반드시 런북 링크를 붙인다.
- 알림 침묵(silence)은 최대 24시간까지만 설정할 수 있다.
