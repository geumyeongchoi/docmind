# 플랫폼팀 주간회의 노트 — 2026-09-04

참석: 김팀장, 이개발, 박개발, 최개발, 정보안(보안팀)

## 결정 사항
1. LGTM 스택 PoC 결과를 승인하고 4분기부터 전 서비스에 순차 적용한다.
2. 트레이싱 샘플링 비율은 기본 10%, 오류 요청은 100%로 한다.
3. 사내 문서 검색은 RAG 방식으로 사내망 모델(Ollama)을 우선 적용한다. 외부 모델은 기밀 이하 문서에만 허용한다.
4. 컨슈머 랙 알림 임계값 완화(1,000 → 5,000)를 확정한다.

## 논의
- 배포 창을 주 3회로 늘리자는 의견. 온콜 부담을 먼저 측정하기로 함.
