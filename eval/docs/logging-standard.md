# 로깅 표준

## 형식
- 운영 환경 로그는 **JSON 한 줄** 형식으로 출력한다. 필드: `ts`, `level`, `service`, `trace_id`, `span_id`, `msg`.
- `trace_id`는 OpenTelemetry 컨텍스트에서 가져온다. 로그와 트레이스는 이 값으로 연결한다.

## 레벨
- ERROR: 사람이 조치해야 하는 상황만. 알림과 1:1로 연결된다.
- WARN: 자동 복구되었지만 반복되면 문제인 상황(재시도, 서킷 오픈).
- INFO: 상태 전이(주문 생성, 배포, 기동/종료).
- DEBUG: 운영 기본 비활성. 임시 활성화 시 24시간 내 원복한다.

## 금지
- 개인정보(이름, 연락처, 주소, 주민번호), 카드번호, 인증 토큰, 비밀번호는 어떤 레벨에서도 남기지 않는다.
- 문서 원문이나 임베딩 벡터를 로그로 내보내지 않는다. 필요하면 앞 80자까지만 남긴다.
- 마스킹은 출력 직전이 아니라 값이 만들어지는 지점에서 한다.

## 보관
- 애플리케이션 로그는 30일, 접근 로그는 90일 보관한다. 이후 아카이브로 이관한다.
