# 코드 리뷰 가이드라인

## 원칙
- 리뷰는 사람이 아니라 코드를 대상으로 한다. 지적은 근거(문서·측정값·재현 절차)와 함께 남긴다.
- 리뷰어는 최소 1명, 결제·인증·개인정보를 다루는 변경은 2명 이상 승인해야 병합할 수 있다.

## 크기와 속도
- PR은 변경 400줄 이하를 권장한다. 초과 시 리뷰 품질이 급격히 떨어지므로 분할한다.
- 첫 리뷰 응답은 영업일 기준 24시간 이내에 남긴다. 24시간을 넘기면 작성자가 다른 리뷰어를 지정할 수 있다.

## 표기
- `[must]` 병합 전 반드시 반영 / `[should]` 반영 권장 / `[nit]` 취향 수준 의견.
- `[nit]`만 남았다면 승인하고 작성자 재량에 맡긴다.

## 체크리스트
- 테스트가 실패 케이스를 포함하는가, 롤백 방법이 있는가, 로그에 개인정보가 남지 않는가.
- 외부 호출에 타임아웃과 재시도 상한이 있는가.
- 설정값이 코드가 아닌 환경변수나 설정 파일에 있는가.
