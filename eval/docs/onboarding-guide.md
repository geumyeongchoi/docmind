# 신규 입사자 온보딩 가이드

## 첫날
- 09:30 인사팀 오리엔테이션(1층 라운지) → 장비 수령(노트북, 사원증) → 계정 발급.
- 사원증은 출입과 사내 카페 결제에 사용한다. 분실 시 재발급 비용은 10,000원이다.

## 첫 주
- 온보딩 버디(선배 사원)가 배정되며 첫 4주간 주 1회 1:1 미팅을 진행한다.
- 필수 교육: 정보보안(2시간), 개인정보보호(1시간), 성희롱 예방(1시간)을 입사 후 2주 이내 이수한다.
- 개발 직군은 개발환경 세팅 가이드(Confluence 'DEV-ONBOARD' 스페이스)를 따른다.

## 수습 기간
- 수습 기간은 **3개월**이며, 수습 기간 급여는 정규 급여의 100%를 지급한다.
- 수습 종료 2주 전 팀장 평가와 본인 회고를 제출하고, 종료 면담에서 정규 전환을 확정한다.

## 사내 도구
- 메신저: Slack / 문서: Confluence / 이슈: Jira / 코드: GitHub Enterprise / 인사: HRIS
- 회의실 예약은 Google Calendar에서 회의실 리소스를 추가하여 예약한다. 최대 2시간 단위이다.
