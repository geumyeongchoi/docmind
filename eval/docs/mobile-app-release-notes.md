# 모바일 앱 릴리스 노트 (2026년 상반기)

## v4.2.0 — 2026-03-12
- 주문 내역 화면에 배송 추적 타임라인을 추가했다.
- 로그인 세션 유지 기간을 14일에서 30일로 늘렸다.
- iOS 15 지원을 종료했다. 최소 지원 버전은 iOS 16, Android 10이다.

## v4.3.0 — 2026-05-07
- 장바구니 담기 응답 속도를 개선했다(p95 820ms → 310ms).
- 알림 설정을 카테고리별로 분리했다.
- 결제 수단에 간편결제 2종을 추가했다.

## v4.3.1 — 2026-05-21
- 특정 기기에서 주소 검색이 실패하던 문제를 수정했다.
- 앱 강제 업데이트 기준을 최신 마이너 버전에서 2개 이전 버전까지로 완화했다.

## 배포 규칙
- 스토어 심사 기간을 고려해 릴리스는 배포 희망일 3영업일 전에 제출한다.
- 단계적 출시는 10% → 50% → 100%로 진행하며 각 단계 최소 12시간 관찰한다.
