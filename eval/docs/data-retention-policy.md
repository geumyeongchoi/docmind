# 데이터 보관·파기 정책

## 보관 기간
- 주문·결제 기록은 전자상거래법에 따라 5년 보관한다.
- 고객 문의 기록은 3년, 접속 로그는 1년 보관한다.
- 마케팅 수신 동의 이력은 동의 철회 후 3년 보관한다.
- 인사 기록은 퇴사 후 3년 보관 후 파기한다.

## 파기
- 파기는 매월 1일 자동 배치로 수행하며 결과를 보안팀에 보고한다.
- 백업본도 동일한 기간이 지나면 파기 대상이다. 백업 보존은 최대 90일이다.
- 파기 불가 사유(분쟁, 수사 협조)가 있으면 법무팀 승인 아래 보류하고 사유를 기록한다.

## 분석용 데이터
- 분석 목적 데이터는 가명처리 후 사용하며, 재식별 가능한 키는 별도 저장소에 분리한다.
- 원본과 가명 데이터를 같은 테이블에 두지 않는다.
