# 장애 대응 런북

## 등급
- **P1**: 전체 서비스 중단 또는 결제 불가. 즉시 전사 공지, 15분 단위 상황 공유.
- **P2**: 일부 기능 장애로 우회 수단이 있음. 1시간 단위 공유.
- **P3**: 사용자 영향이 미미한 오류. 정규 근무시간에 처리.

## 절차
1. 최초 인지자가 `#incident` 채널에 스레드를 열고 등급을 선언한다.
2. 인시던트 커맨더(IC)를 지정한다. 기본값은 해당 서비스 온콜 담당자다.
3. 커뮤니케이션 담당자는 IC와 분리한다. IC가 직접 고객 공지를 쓰지 않는다.
4. 복구를 원인 분석보다 우선한다. 롤백이 가능하면 원인 분석 전에 롤백한다.

## 사후
- P1·P2는 종료 후 5영업일 이내에 포스트모템 문서를 작성한다.
- 포스트모템은 **비난 없는(blameless)** 형식으로 작성하며, 재발 방지 액션에 담당자와 기한을 반드시 적는다.
- 액션 아이템은 다음 스프린트 백로그에 등록한다.
