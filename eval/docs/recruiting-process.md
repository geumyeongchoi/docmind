# 채용 프로세스 (개발 직군)

## 단계
1. 서류 전형 — 접수 후 5영업일 이내 결과 통보.
2. 과제 또는 라이브 코딩 — 과제는 제출 기한 7일, 예상 소요 4시간을 넘지 않게 설계한다.
3. 1차 기술 면접 — 60분, 현업 개발자 2인.
4. 2차 컬처핏 면접 — 45분, 팀장과 인접 팀 리더.
5. 처우 협의 및 레퍼런스 체크(지원자 동의 시).

## 원칙
- 면접 질문은 직무와 무관한 개인 신상(결혼, 출산 계획, 가족 관계)을 묻지 않는다.
- 평가는 면접 종료 후 24시간 이내에 기록한다. 다른 면접관 평가를 보기 전에 작성한다.
- 최종 결과는 마지막 면접 후 7영업일 이내 통보한다.
