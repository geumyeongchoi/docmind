# 레거시 배치 운영 노트

## 야간 배치 일정
- `BAT_SETTLE_001` 정산 배치: 매일 02:00 시작, 평균 40분 소요.
- `order-reconcile` 주문 대사 배치: 매일 03:00 시작, 평균 12분 소요.
- `BAT_STAT_010` 통계 집계: 매일 04:00 시작. 실패해도 재실행으로 복구 가능하다.

## 실패 대응
- 배치 실패 알림은 `#batch-alert` 채널로 전달된다. 정산 배치 실패는 P2로 취급한다.
- 재실행은 멱등하도록 설계되어 있으며, 같은 영업일에 한해 안전하게 반복 실행할 수 있다.
- 3회 연속 실패하면 자동 재실행을 중단하고 담당자를 호출한다.

## 주의
- 정산 배치는 마감 데이터를 읽으므로 01:00~02:00 사이에 주문 데이터를 수정하면 안 된다.
- 배치성 API 호출은 야간 시간대(01:00~06:00)에 수행하고 사전에 플랫폼팀에 공지한다.
