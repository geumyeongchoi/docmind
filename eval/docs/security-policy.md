# 정보보안 규정

## 계정과 비밀번호
- 비밀번호는 최소 12자 이상, 영문 대소문자·숫자·특수문자 중 3종 이상을 조합한다.
- 비밀번호는 **90일마다 변경**하며, 최근 5개와 동일한 비밀번호는 사용할 수 없다.
- 모든 사내 시스템은 2단계 인증(MFA)을 의무 적용한다. 인증 앱은 회사 표준인 Authenticator를 사용한다.

## 기기 관리
- 업무용 노트북은 디스크 암호화(FileVault/BitLocker)를 활성화하고, 화면 잠금은 5분 이내로 설정한다.
- 개인 USB 저장장치 사용은 금지하며, 외부 반출 자료는 DRM 시스템을 통해 승인 후 전달한다.
- 퇴사 시 기기는 마지막 근무일에 IT팀에 반납한다.

## 데이터 등급
- 데이터는 공개 / 내부 / 기밀 / 극비 4등급으로 분류한다.
- 기밀 이상 데이터는 사외 클라우드(개인 드라이브, 외부 AI 서비스 포함)에 업로드할 수 없다.
- 고객 개인정보는 극비로 분류하며 접근 로그를 1년간 보관한다.

## 사고 신고
- 보안 사고(계정 탈취 의심, 분실, 악성코드 감염)는 인지 즉시 보안팀(security@company.local)에 신고한다. 신고 지연에 대한 불이익은 없다.
