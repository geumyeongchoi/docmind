# 배포 체크리스트

## 배포 전
- 변경 사항이 배포 노트에 정리되어 있고, 롤백 방법이 한 줄로 적혀 있는가.
- DB 마이그레이션이 있다면 **하위 호환**인가(컬럼 삭제는 두 번의 배포로 나눈다).
- 피처 토글로 감쌌는가. 토글 기본값은 off 인가.
- 부하가 늘어나는 변경이면 사전에 용량 산정을 했는가.

## 배포 중
- 카나리 10%로 15분 관찰 후 전체 배포한다.
- 관찰 지표: 5xx 비율, p99 지연, 컨슈머 랙, CPU·메모리.
- 5xx 비율이 배포 전 대비 2배를 넘으면 즉시 롤백한다.

## 배포 후
- 30분간 대시보드를 확인하고 `#deploy` 채널에 결과를 남긴다.
- 배포 창은 화·목 14:00~16:00이며 금요일 배포는 금지한다.
