# 공통 오류 코드표

응답 본문은 RFC 9457 problem+json 형식이며 `type`, `title`, `status`, `detail`, `instance` 를 포함한다.
아래 코드는 `type` URI 의 마지막 경로 조각이다.

| 코드 | HTTP | 의미 | 클라이언트 조치 |
|---|---|---|---|
| E1001 | 400 | 요청 본문 검증 실패 | 필드 확인 후 재요청 |
| E1002 | 400 | 지원하지 않는 파일 형식 | PDF·DOCX·MD·TXT 만 허용 |
| E2001 | 401 | 토큰 없음 또는 만료 | 토큰 재발급 |
| E2002 | 403 | 권한 부족 | 권한 신청 |
| E3001 | 404 | 리소스 없음 | 식별자 확인 |
| E4012 | 409 | 여신 한도 초과 | 한도 확인 후 재시도 |
| E4020 | 409 | 재고 부족 | 수량 조정 |
| E4090 | 409 | 멱등키 중복 | 이전 응답 재사용 |
| E5001 | 429 | 속도 제한 초과 | `Retry-After` 만큼 대기 |
| E9001 | 500 | 내부 오류 | 지수 백오프 재시도 |
| E9002 | 503 | 의존 서비스 일시 장애 | 지수 백오프 재시도 |

재시도는 5xx와 429에만 적용하며, 4xx는 재시도하지 않는다.
