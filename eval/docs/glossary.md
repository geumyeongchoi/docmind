# 사내 용어집

- **여신**: 고객에게 부여한 외상 한도. 주문 시 차감되고 입금 시 복구된다. 한도 초과는 오류 코드 E4012.
- **듀얼라이트(dual write)**: 레거시와 신규 시스템에 동시에 기록하는 전환 기법. 피처토글 `order.write-mode`로 제어한다.
- **대사(reconciliation)**: 두 시스템의 데이터가 일치하는지 대조하는 작업. 주문 대사는 매일 03:00 배치로 수행한다.
- **컷오버**: 레거시에서 신규 시스템으로 트래픽을 완전히 넘기는 시점.
- **온콜**: 장애 대응 당번. 1차와 2차로 나누며 매주 수요일 10:00에 교대한다.
- **런북**: 특정 장애 상황의 대응 절차를 적어 둔 문서. 알림에는 반드시 런북 링크를 붙인다.
- **포스트모템**: 장애 종료 후 작성하는 사후 분석 문서. 비난 없는 형식으로 쓴다.
- **SLO**: 서비스 수준 목표. 알림 임계값은 SLO를 기준으로 정한다.
- **RED 대시보드**: Rate(요청량), Errors(오류), Duration(지연)을 한 화면에 모은 기본 대시보드.
- **멱등키(Idempotency-Key)**: 같은 요청이 중복 전달되어도 한 번만 처리되게 하는 36자 UUID 헤더.
- **카나리 배포**: 새 버전을 일부 트래픽에만 먼저 노출해 관찰하는 배포 방식. 기본 10%로 15분 관찰한다.
- **HRIS**: 인사 시스템. 재택근무 신청과 휴가 신청을 여기서 한다.
