# 레거시 주문 시스템 기술 노트 (외식UP 채널)

## 프로시저 PRC_SOOROU001
- **PRC_SOOROU001 프로시저는 레거시 채널의 주문 저장(주문 헤더·상세·여신 차감)을 한 트랜잭션으로 처리한다.**
- 입력: 고객코드, 배송일, 상품 목록(JSON) / 출력: 주문번호(ORD-YYYYMMDD-NNNNNN).
- 실패 시 SQLSTATE와 함께 롤백되며, 오류 코드 E4012는 여신 한도 초과, E4020은 재고 부족을 의미한다.

## MSA 전환 (듀얼라이트)
- 2026년 6월부터 주문 저장은 Order Service(v2)로 이관 중이다. 피처토글 `order.write-mode`가 DUAL이면 프로시저와 v2에 모두 기록하고, V2이면 v2만 기록한다.
- 토글은 요청 진입점에서 1회 읽어 하위로 전달한다(요청 중간 변경 방지).
- 컷오버 후 6주간 v1/v2 주문이 공존하며, 대사 배치 `order-reconcile`이 매일 03:00에 실행된다.

## 결제
- 카드결제 승인/취소 알림은 Kafka 토픽 `payment.card.events`로 발행되며 알림톡 발송 컨슈머가 구독한다.
- 멱등 키는 36자(UUID) 형식이며 Order Service 계약을 따른다.
