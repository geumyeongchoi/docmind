# 개인정보 처리 실무 가이드

## 수집
- 필요한 최소 항목만 수집한다. 선택 항목은 미동의해도 서비스 이용이 가능해야 한다.
- 만 14세 미만은 법정대리인 동의 없이 가입할 수 없다.

## 접근
- 개인정보 테이블 접근은 신청·승인 기록이 남는 경로로만 허용한다. 직접 DB 접속은 금지한다.
- 접근 권한은 분기마다 재검토하며, 3개월간 미사용 권한은 자동 회수한다.
- 고객 개인정보는 극비 등급이며 접근 로그를 1년간 보관한다.

## 유출 대응
- 유출 인지 시 **24시간 이내** 보안팀·법무팀에 보고하고, 관계 법령에 따라 신고 절차를 진행한다.
- 이용자 통지는 지체 없이 하되, 피해 확산 방지 조치를 함께 안내한다.

## 위탁
- 처리 위탁 시 위탁계약서에 재위탁 금지와 파기 의무를 명시한다.
- 위탁사 점검은 연 1회 이상 수행하고 결과를 기록한다.
